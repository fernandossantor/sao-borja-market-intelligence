## Gramática narrativa

A coleção passa a seguir:

**estrutura → demanda → consumidor/jornada → competição → diagnóstico → decisão → monitoramento.**

No Geral, o arco principal é:

**território → base econômica → renda e capacidade de consumo → circulação → fronteira/fluxos → consumidor → mercados setoriais → diagnóstico territorial → decisão empresarial.**
