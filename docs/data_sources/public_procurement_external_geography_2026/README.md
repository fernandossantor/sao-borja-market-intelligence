# PMSB — geografia dos credores externos no core de compras/contratações — 2026

Camada exploratória, não canônica.

O denominador externo contém apenas CNPJs sem estabelecimento ativo da mesma
raiz em São Borja. A geografia é a sede cadastral do CNPJ exato no snapshot
RFB 2026-08, não necessariamente o ponto físico de entrega ou produção.

Resultados permanecem exploratórios porque os bytes RFB foram transportados
por espelho após timeout do host oficial.
