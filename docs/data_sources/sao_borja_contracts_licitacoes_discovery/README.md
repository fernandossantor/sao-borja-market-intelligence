# São Borja — descoberta de rotas históricas de contratos e licitações

Fonte: Portal da Transparência da Prefeitura de São Borja.

Objetivo: identificar rotas e parâmetros reproduzíveis para contratos/licitações que possam complementar a lacuna histórica de credores do SIAPC. Esta etapa registra somente estrutura de interface e rotas, sem dados pessoais.
