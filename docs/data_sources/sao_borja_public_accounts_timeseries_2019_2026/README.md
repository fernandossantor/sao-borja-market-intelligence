# São Borja — contas públicas / credores — cobertura temporal 2019–2026

Camada exploratória, não canônica.

Fonte: Portal da Transparência da Prefeitura de São Borja, consulta pública
de despesas por credor.

Objetivo desta etapa: verificar se a mesma rota reproduz séries anuais
comparáveis de empenhado/anulado/liquidado/pago e preservar somente CNPJ em
detalhe. CPF permanece agregado por minimização de dados pessoais.

A série de credores NÃO é ainda série de compras públicas. Antes disso devem
ser auditadas rubricas, instrumentos e comparabilidade entre exercícios.

2026 é parcial até a data de atualização do portal.
