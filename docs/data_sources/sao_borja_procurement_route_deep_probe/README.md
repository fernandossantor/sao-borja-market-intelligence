# Portal da Transparência de São Borja — deep probe contratos/licitações

Fonte: Portal da Transparência da Prefeitura de São Borja.

Objetivo: identificar rotas e parâmetros públicos reproduzíveis para histórico de contratos/licitações, sem inferir que contrato equivale a pagamento.

O teste de `/acordos/buscarExercicios/<id>` usa somente IDs candidatos e registra apenas respostas não vazias/metadados. Nenhum CPF/nome de pessoa física é persistido.
