# TCE-RS/SIAPC — teste de conectividade do runner

Diagnóstico técnico para separar indisponibilidade dos dados de bloqueio de transporte entre GitHub Actions e `dados.tce.rs.gov.br`.

Foram testados HTTPS/HTTP, CKAN e a rota oficial por órgão `empenhos/2025/58000.csv.{7z,zip}`, forçando IPv4.

Este teste não contém dados de credores.
