# Portal PMSB — hierarquia após seleção do credor

Camada exploratória, não canônica.

Objetivo: identificar a próxima camada pública de detalhamento após selecionar
um credor na consulta de despesas. Foram usados três CNPJs de naturezas
distintas somente para descoberta de schema/endpoints; nenhum caso individual
é usado como inferência territorial.
