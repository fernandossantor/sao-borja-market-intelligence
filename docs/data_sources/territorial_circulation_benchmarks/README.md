# Circulação territorial — descoberta de benchmarks oficiais

Camada exploratória, não canônica.

Fontes:
- DEE/SPGG-RS — MIP-RS 2019, tabela 117 produtos x 52 atividades.
- TCE-RS / LicitaCon — Dados Abertos de contratos da PM de São Borja.

Objetivo: calibrar conceitualmente geração de valor, consumo intermediário,
remunerações/excedente e testar a retenção/vazamento de compras públicas
por localização do fornecedor.

Nenhum coeficiente estadual deve ser tratado como coeficiente municipal sem
marcação explícita de benchmark/estimativa.
