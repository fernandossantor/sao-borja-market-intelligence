# Cadernos Setoriais

Os cadernos setoriais usam a Base Territorial comum sem duplicar a sua auditoria.

Fluxo:

`Base Territorial → integração Base × POM → evidência setorial → diagnóstico → lacuna decisória → nova pesquisa somente quando necessária`.

## Ordem de desenvolvimento

1. **Bens não essenciais — v001 concluído**
2. Alimentação fora do lar e serviços
3. Saúde, higiene e cuidados pessoais
4. Bens essenciais

A ordem é analítica, não de importância econômica.

## Regras

- manter POM qualitativa como indício qualitativo;
- tratar survey não probabilístico como descritivo da amostra;
- usar fontes oficiais da Base Territorial para macroambiente;
- aplicar REGIC somente com correspondência conceitual defensável;
- bloquear market share/retenção/vazamento sem dado monetário;
- preservar versões anteriores e documentação no Drive.
