# PMSB — diagnóstico da rota de contratos

Probe exploratório da página oficial `https://transparencia.saoborja.rs.gov.br/acordos`.

Objetivo: identificar valores de instituição/exercício e rotas dinâmicas para futura extração
censitária de contratos. O probe não promove valores de contratos e não substitui execução
financeira.

A descoberta desta rota deve ser tratada separadamente da série de processos de Licitações
e da série de pagamentos.
