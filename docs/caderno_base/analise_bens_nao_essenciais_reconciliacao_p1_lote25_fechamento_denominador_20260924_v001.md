# Bens não essenciais — reconciliação P1 — lote 25 — fechamento do denominador exploratório — 24/09/2026

## 1. Objeto

Este lote trata os **11 P1 remanescentes** após o lote 24.

O objetivo não é encerrar toda pendência jurídica, mas responder a uma pergunta mais estrita:

> a pendência ainda pode alterar o número de operações/storefronts no primeiro cenário-base exploratório?

Quando a presença operacional atual é suficientemente demonstrada, a identidade jurídica pendente deixa de bloquear o denominador e passa para P2.

## 2. Critério metodológico

A resolução P1 adotou a seguinte regra:

- **presença atual demonstrada + identidade jurídica pendente** → storefront pode entrar no cenário-base, identidade passa a P2;
- **CNPJ histórico baixado/inapto** → não é tratado como CNPJ ativo, mesmo quando a marca permanece operacional;
- **CNPJ candidato forte** → não é promovido canonicamente sem vínculo direto, mas sua incerteza não bloqueia o número de operações;
- **duas pessoas jurídicas com a mesma marca** → não são contadas como duas lojas sem evidência operacional independente.
