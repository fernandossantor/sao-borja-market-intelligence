# PMSB — auditoria semântica do core de compras/contratações — 2026 — v003

Fonte: Portal da Transparência PMSB, detalhe integral do CORE_PROCUREMENT,
reconciliado a R$72.039.491,18.

Esta camada usa o detalhe de empenhos para medir cobertura da revisão semântica
dos maiores pares externos CNPJ × rubrica. "Revisado" significa que o par
recebeu classificação semântica documental/analítica no probe prioritário;
não significa que todos os itens de todos os empenhos foram individualmente
inspecionados.

Rubrica orçamentária, ação administrativa, objeto contratual e item adquirido
permanecem conceitos distintos.
