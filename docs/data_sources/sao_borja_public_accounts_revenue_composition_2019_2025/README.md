# São Borja — composição da receita corrente bruta — 2019–2025

Fonte: Tesouro Nacional / SICONFI, DCA Anexo I-C.
Geografia: São Borja/RS.
Unidade: R$ correntes por exercício.

O arquivo seleciona as contas de primeiro nível abaixo de Receitas Correntes
(1.x.0.0.00.0.0) e calcula sua participação na receita corrente bruta.
A finalidade é explicar a composição anual, em especial a queda excepcional da
razão transferências/receita observada em 2022.

As participações são calculadas. Os valores monetários são observados.
Não chamar receita corrente não-transferência de "receita própria" sem revisar
a composição das categorias.
