# Portal da Transparência de São Borja — menu de despesas por credor

Camada exploratória, não canônica.

Reprodução da chamada pública usada pela página oficial de despesas:
POST /despesas/loadLink/3

Período piloto: 01/01 a 18/09/2026, com data de importação lida dinamicamente
da própria página. O objetivo desta etapa é descobrir os parâmetros/endpoints
de navegação por credor; ainda não é uma extração de valores.
