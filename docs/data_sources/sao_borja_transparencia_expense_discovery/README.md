# Portal da Transparência de São Borja — descoberta da rota de despesas

Camada exploratória, não canônica.

Fonte oficial municipal:
https://transparencia.saoborja.rs.gov.br/despesas

Objetivo: identificar endpoints e parâmetros públicos usados pela interface
de consulta de despesas por credor, para obter empenhado/liquidado/pago sem
depender do host binário do TCE-RS.

A descoberta preserva somente estrutura de página, scripts públicos e menções
a endpoints. Nenhum valor é inferido. Uma etapa posterior deverá reproduzir
a consulta de 2026, validar schema e conciliar totais antes da classificação
territorial de credores.
