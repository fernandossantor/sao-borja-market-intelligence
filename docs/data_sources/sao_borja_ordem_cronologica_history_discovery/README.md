# São Borja — Ordem Cronológica dos Pagamentos — descoberta histórica

Fonte: Portal da Transparência da Prefeitura de São Borja.

Objetivo: verificar se a consulta pública de ordem cronológica pode fornecer uma rota histórica reproduzível de pagamentos, complementando a lacuna de credores do SIAPC.

Esta camada registra apenas estrutura de interface, anos, rotas e parâmetros. Nenhum dado pessoal é persistido.
