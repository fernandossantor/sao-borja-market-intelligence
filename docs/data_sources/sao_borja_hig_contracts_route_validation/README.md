# PMSB — validação de contratos conhecidos da Fundação Ivan Goulart

Validação exploratória da rota oficial do Portal da Transparência de São Borja.
O arquivo cruza números de contratos já documentados em fontes oficiais com os
identificadores internos da rota `/acordos/view/{id}`.

Esta validação comprova presença/estrutura contratual, mas não transforma valor
contratado em valor executado, liquidado ou pago.
