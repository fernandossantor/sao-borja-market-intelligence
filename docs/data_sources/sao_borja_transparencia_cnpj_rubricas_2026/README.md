# PMSB — pagamentos a credores CNPJ por rubrica — 2026

Camada exploratória, não canônica.

Fonte oficial municipal: Portal da Transparência de São Borja.
Período: 01/01/2026 até a data de atualização indicada pelo portal.

A extração percorre somente credores CNPJ com pagamento positivo e agrega os
empenhos por rubrica orçamentária. O objetivo é separar, em etapa posterior,
despesas potencialmente associadas à aquisição de bens/serviços de
transferências, dívida, tributos, benefícios e outras naturezas.

Esta camada NÃO classifica automaticamente uma rubrica como compra pública
elegível e NÃO classifica CNPJ como local/externo. Ambas as decisões exigem
regras separadas e auditáveis.
