# PMSB — função orçamentária × geografia do credor — core de compras/contratações — 2026

Camada exploratória, não canônica.

O arquivo agrega somente pagamentos positivos em rubricas CORE_PROCUREMENT.
Função/subfunção/programa/ação são classificações administrativas da despesa
e não equivalem automaticamente a setores de mercado.

O objetivo é identificar em quais finalidades públicas a primeira rodada do
pagamento está mais ancorada localmente ou mais exposta a credores externos.

A geografia cadastral usa RFB 2026-08 transportada por espelho nesta execução;
portanto os resultados permanecem exploratórios até reconciliação oficial.
