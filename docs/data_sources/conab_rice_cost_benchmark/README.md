# Conab — custo de produção do arroz irrigado — benchmark

Camada exploratória, não canônica.

Fonte primária: Conab, série histórica do custo de produção do arroz
irrigado 2002–2025, atualizada em 24/07/2025.

Objetivo: localizar estruturas recentes de Uruguaiana/Itaqui como benchmark
regional para insumos, máquinas e demais componentes do custo.

Regra: custo regional não é vazamento territorial e não deve ser aplicado
como coeficiente observado de São Borja sem informação sobre origem dos
fornecedores.
