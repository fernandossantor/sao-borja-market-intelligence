# TCE-RS/SIAPC — descoberta CKAN de empenhos da Prefeitura de São Borja — 2019–2025

Objetivo: substituir o teste legado de URL por órgão, que não entregou bytes em 2019–2025, por descoberta reproduzível dos recursos atualmente publicados no catálogo CKAN oficial do TCE-RS.

Fonte: Dados Abertos TCE-RS / SIAPC, conjunto “Despesa orçamentária por empenhos”.
Órgão-alvo: PM DE SÃO BORJA (código TCE 58000).
Período: 2019–2025.

Esta etapa persiste apenas consultas CKAN, metadados dos recursos, hashes dos arquivos baixados e inventário de schema. Não persiste linhas de credores, nomes, CPF/CNPJ ou históricos de empenho.

Interpretação: sucesso técnico da execução não implica disponibilidade de recurso por ano. Ver download_manifest.csv e schema_inventory.csv.
