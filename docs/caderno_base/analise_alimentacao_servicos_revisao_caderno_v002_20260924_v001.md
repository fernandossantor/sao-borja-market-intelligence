## 9. Diagnóstico corrente de Serviços

O mercado de Serviços não deve ser tratado como homogêneo.

A estrutura formal do recorte é numericamente dominada por:
1. salões/barbearias;
2. oficinas automotivas;
3. clínicas/consultórios;
4. assistências técnicas/reparos.

Ao mesmo tempo, a POM identifica uma jornada transversal de:
descoberta → reputação → contato → resposta → agendamento → prestação → pós-serviço.

A estratégia deve combinar essas duas dimensões sem atribuir automaticamente os percentuais do survey a cada submercado.

## 10. Diagnóstico corrente de Alimentação

A competição continua baseada em valor composto:

**qualidade + preço + atendimento + ambiente + descoberta digital + conveniência + hospitalidade.**

O PNAE/B2G adiciona uma oportunidade institucional para fornecedores da cadeia de alimentos, mas permanece conceitualmente separado do consumo fora do lar.
