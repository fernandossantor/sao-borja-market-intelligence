# TRU/MIP-RS 2019 — benchmarks setoriais para circulação territorial

Camada exploratória, não canônica.

Fonte oficial: DEE/SPGG-RS — Tabelas de Recursos e Usos do RS 2019.

Finalidade: obter benchmarks estaduais de valor da produção, consumo
intermediário e componentes do valor adicionado para calibrar cenários de
geração versus retenção/circulação em São Borja.

Regra: coeficientes estaduais são benchmarks estruturais, não estimativas
municipais observadas.
