## Regras de interpretação

- São Borja é a unidade territorial principal.
- Dado regional permanece regional.
- Observado, calculado, estimado, benchmark, hipótese, interpretação e recomendação permanecem separados.
- Correlação não é causalidade.
- Unidades/cadastros não são participação econômica.
- REGIC não mede gasto.
- Demanda modelada não é faturamento.
- POM qualitativa não produz prevalência.
- Survey n=153 não representa a população.
- Contrato não é pagamento.
- Fluxos heterogêneos não são aditivos.
- Sem nova pesquisa primária no escopo corrente.
