# Portal PMSB — licitações — histórico 2019–2025

**Fonte observada:** Portal da Transparência da Prefeitura Municipal de São Borja — módulo Licitações.

**Instituição usada:** código 1 no portal, correspondente à Prefeitura Municipal de São Borja nas rotas administrativas já auditadas.

**Período:** 2019–2025.

**Unidade principal:** processos de licitação publicados pelo endpoint dinâmico `/licitacoes/pesquisarLicitacoes`.

A extração reconcilia, para cada exercício, a contagem `records` declarada pelo endpoint com os IDs únicos extraídos.

O arquivo de processos preserva somente campos públicos do cadastro do procedimento: exercício, ID, modalidade, número, código, objeto e situação. Não contém pagamentos.

**Limitação central:** processo licitatório ≠ contrato ≠ empenho ≠ pagamento. Esta fonte serve para estrutura de demanda pública, objetos e instrumentos de contratação. Não deve ser somada à despesa paga do SICONFI nem interpretada como valor monetário realizado sem outra evidência.
