# Portal PMSB — comparação de parâmetros de despesas por exercício

Auditoria técnica da estrutura `oParametros` produzida por `/despesas/loadLink/3`
para 2019–2026. O objetivo é localizar parâmetros vazios ou diferenças de
exercício que expliquem a falha SQL da rota histórica de credores.

Parâmetros cujo nome sugere identificador pessoal/credor são redigidos quando
não vazios. Esta camada não contém linhas de credores.
