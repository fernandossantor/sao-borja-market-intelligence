# PE39/2026 — participantes dos 18 condutores prioritários

Universo dirigido: 22 CNPJs extraídos das tabelas de propostas da Ata Final oficial
do PE39/2026 para os 18 itens prioritários.

Territorialização cadastral: RFB Dados Abertos CNPJ, competência 2026-08,
por CNPJ exato e por raiz com estabelecimento ativo em São Borja (TOM 8863).

O arquivo rfb_transport_sources.txt registra, arquivo a arquivo, se os bytes
vieram do host oficial ou do espelho de transporte controlado. Se houver uso
de espelho, a classificação deve permanecer exploratória até reconciliação
com a fonte oficial.

Localidade cadastral não equivale a origem física do produto, estoque,
retenção econômica, capacidade de escala ou competitividade.
